
# ROVER-PROJECT-IUB

Af first we need to connect ST-Link with STM32 Black Pill.

<img width="1920" height="1080" alt="STLink_STM32_diagram" src="https://github.com/user-attachments/assets/5ce3cf26-a7c9-4146-a267-ea1c4e480fe0" />

1. After that open Arduino IDE and paste this urf in preferences section: https://github.com/stm32duino/BoardManagerFiles/raw/main/package_stmicroelectronics_index.json
   
2. Open Board Manager and search "STM" and download the package. Version 2.12.0 specificly

3. Paste the code rover.ino from this github repository and start uploading.
   NOTE: While compailing press the BOOT button until code is succesfully uploaded.
